# Benchmarks

This file is reserved for **measured benchmark results from the executed notebook**.

The final benchmark table must include:

- commercial vs open-weight provider comparison;
- structured-output pass rates;
- attack block rate and legitimate false-positive rate;
- latency and cost;
- cached-input-token evidence where supported;
- response/semantic cache measurements;
- before/after optimization rows;
- evaluation verdict beside every cost optimization;
- measured self-host throughput;
- self-host break-even calculation.

Do not enter estimated or vendor-advertised numbers as if they were measured project results.
